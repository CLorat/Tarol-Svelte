# @clorat/tarol-admin

An admin UI for [Tarol](https://github.com/CLorat/Tarol-Net) backends, over the admin entry `MapTarolAdmin` of
`Tarol.Operations`: dead letters (re-drive one or all, discard), projection versions (drop a superseded one) and a data
subject's personal data (export as a JSON download, erase after typing the subject's id). Svelte 5, built from
`@clorat/tarol-components` and `@clorat/tarol-design`.

```svelte
<script lang="ts">
  import { AdminApp, adminDe } from '@clorat/tarol-admin';
</script>

<!-- inside ThemeRoot, after setTarol(client); on a route of your app -->
<AdminApp prefix="/tarol/admin" messages={adminDe} />
```

| What | Behaviour |
|---|---|
| Access | the backend decides: a user without its admin role (`tarol-admin` in the sample) sees the 403 `Auth.Forbidden` message |
| Dead letters | the kinds from `GET {prefix}/dead`; keyset pages of 50; re-drive, discard and "re-drive all" after a confirmation |
| Projections | versions with state, rows and bytes; drop only for a superseded version (the backend refuses the current one: `Projection.Drop`) |
| Data subject | `tenant` is required (the empty GUID for data without one); an erasure that did not finish everywhere (409 `DataProtection.ErasureIncomplete`) names the participants and can be repeated |
| Texts | `adminEn` (default) or `adminDe`, in front of the app's catalogue; every refusal shows its code's message and its reference (`Tarol-Request-Id`) |
| Client | generated by `@clorat/tarol-codegen` from the admin part of the backend's OpenAPI document (`openapi.admin.json`, paths relative to the prefix); `adminErrors` lists the codes |

Size: 5.98 KB gzip (budget 6 KB, SV-18; without Svelte and the other `@clorat` packages). No global state; nothing runs
